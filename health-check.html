What we audit

Contrast & WCAG AA

Calculates real contrast ratios between every text/background colour pair. Fails anything under 4.5:1.

How to use the report

Fix critical issues first

Start with invisible text, broken images, invalid links, and Outlook-breaking layout CSS. These are the problems most likely to make a signature unusable for recipients.

Then clean up warnings

Warnings usually cover contrast, image weight, missing dimensions, and mobile width. They may not break every inbox, but they reduce trust and make signatures harder to read.

Re-test after changes

Paste the repaired HTML back into the checker after each round. A good production signature should be readable in dark mode, lightweight, and free of tracking pixels.

Common failures this catches

Browser-only layouts

Signatures built with flexbox, grid, external CSS, or absolute positioning often look fine in a web preview and then collapse in classic Outlook.

Images that only work locally

Local file paths and pasted image blobs can show up for you but fail for everyone else. Hosted HTTPS image URLs are safer for logos and headshots.

Dark-mode surprises

Low-contrast grey text, transparent logo artwork, and pure black text can be recoloured by Gmail and other clients in ways that make the signature hard to read.

Signature audit checklist

Before sending to customers

Run the check after changing colours, images, disclaimers, badges, or CTA links. Small visual edits can add weight, lower contrast, or introduce broken image URLs.

Before rolling out to a team

Test one approved signature first, then duplicate it for staff. This prevents every person from copying a slightly different logo size, font, link, or disclaimer.

After a redesign

Check the signature again whenever your website, booking link, logo file, tracking links, or brand colours change. Email signatures often keep stale assets long after the site is updated.

Repair path

Use real text

Names, roles, phone numbers, emails, and addresses should be selectable text. Avoid turning the whole signature into one image because it hurts accessibility and deliverability.

Host images properly

Use public HTTPS URLs for profile photos, logos, and badges. Add width, height, and alt text so recipients still understand the signature when remote images are blocked.

Keep layout conservative

Use table-based HTML and inline styles for production signatures. Browser CSS such as grid, flexbox, external stylesheets, and background images is fragile inside email clients, especially older Outlook builds.
