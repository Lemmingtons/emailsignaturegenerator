How to Add or Change Your Email Signature in Gmail

By Email Signature Generator · Updated 25 October 2026 · 8 min read

On desktop: open Gmail, select Settings → See all settings, find Signature under General, add or paste the signature, choose defaults for new messages and replies, then Save Changes. To change a signature, select it in the same place, edit it and save again. Gmail’s Android and iPhone/iPad apps have a separate mobile-signature setting.

Google’s current instructions confirm these paths, support multiple desktop signatures, and state that a Gmail signature can contain up to 10,000 characters. Use Google’s official Gmail signature guide beside the steps below.

Add or paste a Gmail signature on desktop

  1. Open Gmail in a desktop browser.
  2. At the top right, select Settings, then See all settings.
  3. Stay in General and scroll to Signature.
  4. Create or select a signature, then type into the editor or paste a prepared rich-HTML signature.
  5. Choose the signature defaults for new emails and replies/forwards. You may deliberately use no default for replies.
  6. Scroll to the bottom and select Save Changes.
  7. Compose a new message, confirm the intended signature appears, and send a test.

How to change your Gmail signature

  1. Open Settings → See all settings and stay on General.
  2. Under Signature, select the signature you want to change from the list on the left.
  3. Edit it in the editor, or select everything inside it and paste your new signature over the old one.
  4. Check the defaults for new emails and replies/forwards still point at the right signature.
  5. Select Save Changes at the bottom of the page. Gmail does not save signature edits until you do.

To use a different signature for one message only, open the message, select the Insert signature pen icon at the bottom of the compose window, and pick another saved signature.

How to remove or turn off a Gmail signature

  • Stop using it: set both defaults to No signature and select Save Changes. The signature stays saved for later.
  • Delete it: select the signature, choose the delete (bin) icon beside it, confirm, then select Save Changes.
  • Mobile: in the Gmail app, turn off Mobile Signature (iPhone) or clear the mobile signature text (Android).

Paste rich HTML without using the wrong product control

In this product, the export button is labelled Copy HTML. There is no separate “Copy for Gmail” button. After unlocking export, use Copy HTML, click inside Gmail’s signature editor, and paste normally with Ctrl+V on Windows or Cmd+V on Mac.

Do not use a plain-text paste command if you want to preserve formatting. After pasting, inspect the editor for an unexpected extra border, missing image, or altered spacing—but do not treat that preview as final proof.

Choose Gmail signature defaults deliberately

Gmail supports multiple signatures. A useful setup is one complete signature for new conversations and a shorter or empty default for replies. When composing, Google also lets you use the Insert signature control to switch signatures for a specific message.

If you use Gmail’s “Send mail as” feature, Google says you can select a different signature for each configured sender address. Confirm the sending address and signature together before sending.

Gmail mobile signatures on Android, iPhone, and iPad

Android

Google’s current Android path is Gmail app → Menu → Settings → choose the Google Account → Mobile signature. Enter the text and confirm. Google also says that if you do not create a mobile signature, new messages use the signature created on your computer.

iPhone and iPad

The current iOS path is Gmail app → Menu → Settings → under Compose and Reply, Signature settings → turn on Mobile Signature → add or edit it → Back to save. Configure each account separately when several accounts are connected.

The mobile control is a simpler app-specific field, so keep essential identity and contact details in text. Send a test from the app you actually use; do not assume the desktop editor and mobile composer behave identically. Google maintains a separate Gmail signature troubleshooting page for issues such as extra lines, missing images, sharing permissions, and formatting limits.

Test the received Gmail signature

  1. Send a new message to another Gmail address and to an Outlook address you control.
  2. Open the received message on desktop and in a narrow mobile inbox.
  3. Click every link and confirm the exact destination.
  4. Check a reply and forwarded message for duplicated or oversized signatures.
  5. Confirm the text still identifies the sender when remote images are unavailable.
