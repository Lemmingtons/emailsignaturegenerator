How to Add an Email Signature in Outlook (2026 Guide)

Updated April 2026 · 5 min read

Adding an HTML email signature to Outlook takes under 2 minutes. This guide covers Outlook for Windows, Outlook for Mac, and Outlook.com — with step-by-step instructions for each.

Outlook for Windows (Microsoft 365 / Outlook 2016–2024)

  1. Open Outlook and click File in the top-left menu.
  2. Click Options, then Mail, then click Signatures…
  3. Under "Select signature to edit", click New. Give your signature a name.
  4. In the editor at the bottom, paste your signature with Ctrl+V.
  5. Under "Choose default signature", set your signature for New messages and Replies/forwards.
  6. Click OK to save.

Outlook for Mac (Microsoft 365 for Mac)

  1. Open Outlook on your Mac.
  2. Click Outlook in the menu bar, then Settings.
  3. Click Signatures.
  4. Click "+" to add a new signature.
  5. Paste your signature with Cmd+V in the editor.
  6. Set it as the default for your account using the dropdown menus.
  7. Close the window to save.

Outlook.com (web browser)

  1. Open Outlook.com in your browser and sign in.
  2. Click the Settings gear icon (top right).
  3. Click "View all Outlook settings" at the bottom of the panel.
  4. Go to Mail → Compose and reply.
  5. Under Email signature, paste your signature with Ctrl+V.
  6. Check "Automatically include my signature on new messages" and "…on messages I forward or reply to".
  7. Click Save.

Why Outlook renders email signatures differently

Outlook for Windows uses Microsoft Word's HTML rendering engine, not a standard web browser. This means some modern CSS features don't work reliably. Specifically:

  • CSS flexbox and grid — not supported. Use HTML tables for layout.
  • Web fonts — Outlook falls back to system fonts. Stick to Arial, Georgia, Verdana, Tahoma, or Trebuchet MS.
  • Background images in divs — partially supported. Avoid relying on them.
  • External CSS files — stripped. All styles must be inline.

Our email signatures use HTML table-based layouts with inline CSS, which is the industry standard for cross-client compatibility — including Outlook.

How to check your Outlook signature looks correct

After adding your signature, compose a test email and send it to a personal Gmail account. This lets you see exactly how the signature renders for your recipients across different email clients.

Common issue: If your signature looks correct in Outlook but broken for Gmail recipients, the likely cause is an image hosted on a private server or corporate network that external recipients can't access. Use publicly hosted image URLs.

Adding your signature on Outlook mobile (iOS and Android)

Outlook's mobile app supports HTML signatures on iOS and Android:

  1. Open the Outlook app on your phone.
  2. Tap your profile photo (top left), then tap the Settings gear icon.
  3. Tap Signature.
  4. Toggle on Per Account Signature.
  5. Type your signature details. (HTML is not directly supported in the mobile editor — use the desktop version for HTML signatures.)

Frequently Asked Questions

How do I add an email signature in Outlook?

In Outlook for Windows: File → Options → Mail → Signatures → New → paste your signature → set as default → OK. In Outlook.com: Settings → View all Outlook settings → Mail → Compose and reply → paste signature → Save.

How do I add an HTML email signature to Outlook without losing formatting?

Copy your signature using the "Copy for Gmail" button (HTML format), then paste with Ctrl+V directly into the Outlook signature editor. Do not use Paste Special or plain text paste, as this strips all formatting.

Why does my email signature look broken in Outlook?

Outlook uses Microsoft Word's HTML engine, which doesn't support modern CSS. Use HTML table-based layouts (not flexbox), email-safe fonts (Arial, Georgia, Verdana), inline CSS only, and publicly hosted images. Our generator handles all of this automatically.
