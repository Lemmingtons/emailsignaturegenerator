How to Add or Change Your Email Signature in Outlook

By Email Signature Generator · Updated 25 October 2026 · 9 min read

Choose your Outlook version first. New Outlook and Outlook on the web use Settings → Accounts → Signatures. Classic Outlook for Windows uses File → Options → Mail → Signatures. Outlook for Mac uses Outlook → Settings → Signatures. The Outlook phone app uses Settings → Signature. To add one, create it and paste; to change one, select it in the same screen, edit and save. Then set the defaults for new messages and replies, and test a received message.

Jump to: New Outlook and web · Classic Outlook · Mac · Change a signature · Remove one · Phone app · Troubleshooting

Microsoft’s current support page separates new Outlook, classic Outlook, and web instructions because the labels and controls differ. Keep its official Outlook signature guide open while following the version-specific steps below.

Add a signature in new Outlook and Outlook on the web

  1. Select Settings.
  2. Open Accounts → Signatures. If several accounts are connected, choose the intended account first.
  3. Select Add signature and give it a distinct name.
  4. Type or paste the signature into the editor.
  5. Choose whether it applies to new messages and to replies/forwards.
  6. Select Save.
  7. Create a new message and use Insert → Signature if you want to choose a saved signature manually.

Microsoft groups new Outlook, Outlook on the web, and Outlook.com on the same current support surface. If an older account still shows different labels, search Settings for “signature” and confirm the Microsoft support tab that matches the interface.

Add a signature in classic Outlook for Windows

  1. Open File → Options.
  2. Select Mail, then Signatures.
  3. Select New, name the signature, and paste or type it into the editor.
  4. Choose the email account plus defaults for new messages and replies/forwards.
  5. Select OK to save, then send a test message.

If Settings → Accounts → Signatures does not exist, you may be in classic Outlook. Microsoft explicitly tells readers to switch to its Classic Outlook instructions when the new-Outlook path does not match.

Add a signature in Outlook for Mac

  1. From the Outlook menu, select Settings.
  2. Under Mail, select Signatures.
  3. Rename the standard signature or add a new one, then type or paste the content.
  4. Close the editor when finished.
  5. Under the default-signature controls, choose the account plus defaults for new messages and replies/forwards.
  6. Send a received-message test from that account.

These labels come from Microsoft’s current Outlook for Mac signature instructions. Microsoft also notes that legacy Outlook for Mac support changes in October 2026, so older screens should be checked against the current support page rather than treated as permanent.

How to change an existing signature in Outlook

Changing a signature happens in the same screen you used to add it. You edit the saved signature rather than creating a new one, so the defaults you set stay in place.

New Outlook and Outlook on the web

  1. Open Settings → Accounts → Signatures.
  2. Pick the signature from the list at the top of the editor.
  3. Edit the text, or select everything in the editor and paste your new signature over it.
  4. Select Save, then open a new message to check it.

Classic Outlook for Windows

  1. Open File → Options → Mail → Signatures. In a new message you can also use Message → Signature → Signatures.
  2. Select the signature under Select signature to edit.
  3. Edit it, or select all with Ctrl+A and paste the new version.
  4. Select Save, then OK.

Outlook for Mac

  1. Open Outlook → Settings → Signatures.
  2. Double-click the signature to open it.
  3. Edit it, or select all with Cmd+A and paste the new version, then close the editor to save.

How to remove or turn off a signature in Outlook

  • Turn it off but keep it: set both defaults, New messages and Replies/forwards, to (none) or No signature, then save.
  • Delete it: select the signature and choose Delete in new Outlook, Outlook on the web and classic Outlook. In Outlook for Mac, select it and click the minus (−) button.
  • Leave it off replies only: keep the new-message default and set replies/forwards to none, or to a shorter reply signature. This keeps long threads readable.

Change your signature in the Outlook app (iPhone and Android)

  1. Tap your profile picture or account icon at the top left.
  2. Tap the Settings gear.
  3. Tap Signature. If you have several accounts, you can set one per account.
  4. Edit the text and go back to save.

The Outlook mobile app has its own Settings → Signature control. Available formatting can vary by app version and account, and Microsoft’s current desktop support page does not document a portable rich-HTML paste workflow for the mobile editor. Use a short text-first mobile signature unless you have tested richer formatting in the exact app version you deploy.

Run a received-message test

  1. Send from the exact Outlook account and version being configured.
  2. Open the message in another Outlook version and in Gmail.
  3. Inspect a narrow mobile inbox for clipping or horizontal overflow.
  4. Click each link and verify the exact destination.
  5. Reply and forward once, then check the image-blocked fallback.
