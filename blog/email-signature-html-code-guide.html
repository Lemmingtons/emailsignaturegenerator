Email Signature HTML Code: A Template That Works in Gmail and Outlook

By Email Signature Generator · Published October 2026 · 8 min read

The short answer: good email signature HTML is old-fashioned on purpose. Lay it out with a <table>, write every style inline in a style attribute, load images from public HTTPS URLs with width and height set, and keep names and phone numbers as real text. Do not paste the code itself into Gmail or Outlook. Open the file in a browser, copy the rendered signature, and paste that into your signature settings. A working template is below.

Email clients are not browsers. Classic Outlook for Windows draws messages with Microsoft Word's rendering engine, Gmail rewrites and strips parts of what you send, and mobile apps shrink everything to fit. Code that looks perfect in Chrome can arrive with its columns stacked, its logo at full size, or its fonts replaced. The rules below are the ones that survive all of them.

A copy-paste email signature HTML template

This is a two-column signature: logo on the left, contact details on the right. Replace the placeholder text, links and image address with your own.

<table role="presentation" cellpadding="0" cellspacing="0" border="0" bgcolor="#ffffff"
       style="background-color: #ffffff; border-collapse: collapse; font-family: Arial, Helvetica, sans-serif;">
  <tr>
    <td bgcolor="#ffffff" style="background-color: #ffffff; padding-right: 14px; border-right: 2px solid #1d4ed8; vertical-align: top;">
      <img src="https://yourcompany.com/email/logo.png" alt="Your Company"
           width="120" height="40"
           style="display: block; width: 120px; height: 40px; border: 0;">
    </td>
    <td bgcolor="#ffffff" style="background-color: #ffffff; padding-left: 14px; vertical-align: top;">
      <p style="margin: 0; font-size: 15px; font-weight: bold; color: #111827;">Alex Morgan</p>
      <p style="margin: 2px 0 8px; font-size: 13px; color: #4b5563;">Operations Manager, Your Company</p>
      <p style="margin: 0; font-size: 13px; line-height: 20px; color: #111827;">
        <a href="tel:+15550100100" style="color: #111827; text-decoration: none;">+1 555 010 0100</a><br>
        <a href="mailto:alex@yourcompany.com" style="color: #1d4ed8; text-decoration: none;">alex@yourcompany.com</a><br>
        <a href="https://yourcompany.com" style="color: #1d4ed8; text-decoration: none;">yourcompany.com</a>
      </p>
    </td>
  </tr>
</table>

The white background, set with both bgcolor and inline CSS on the table and each cell, keeps the dark text readable when a recipient reads mail in dark mode. Every choice in it is deliberate. The sections below explain why, so you can change the design without breaking it.

The rules that keep signature HTML intact

1. Use tables for layout

Classic Outlook for Windows ignores flexbox, grid, floats and most positioning, so a <div> layout collapses into a single column there. Tables are the one layout method every major client understands. Nest a second table inside a cell if you need rows within a column. Add role="presentation" to each layout table so screen readers do not announce your signature as a data table.

2. Put every style inline

Signature editors strip <style> blocks and class names when you paste, and replies and forwards strip more. A style only survives when it sits in a style attribute on the element it affects. That is why the template repeats colours and font sizes on each paragraph and link rather than declaring them once.

3. Stick to CSS that Outlook understands

  • Safe: font-family, font-size, font-weight, color, line-height, text-decoration, padding on table cells, solid borders.
  • Use with care: margin on paragraphs (set it explicitly, or Outlook adds its own spacing), background-color (set it on the outer table and its cells, as above, or dark mode can put your dark text on a dark background).
  • Avoid: border-radius, box-shadow, background-image, max-width, flexbox, grid, web fonts and anything animated. Outlook for Windows ignores them, so the design must still work without them.

4. Use web-safe fonts with a fallback

Custom web fonts do not load in most inboxes. Pick a font the recipient already has, such as Arial, Helvetica, Verdana, Tahoma, Georgia or Times New Roman, and always end the stack with a generic family like sans-serif.

5. Host images and size them twice

Load every image from a public HTTPS address. Gmail and Outlook strip images written into the code as data: URIs, and pasted or attached images can arrive as attachments. Set the size both as HTML attributes (width="120" height="40") and in the inline style. Outlook for Windows reads the attributes and ignores CSS sizing, while other clients use the CSS. Save the file at about twice the display size so it stays sharp on high-resolution screens. Our email signature size guide lists dimensions for logos, headshots and icons, and the logo guide covers hosting and dark mode.

6. Keep the details as text, with real links

Many recipients block images until they choose to load them, and screen readers cannot read text inside a picture. Keep your name, role and contact details as text. Link phone numbers with tel: and email addresses with mailto: so they work with one tap on a phone, and give each image short alt text such as your company name.

7. Keep it small

Gmail allows 10,000 characters per signature, and that count includes the HTML. The template above is around 1,300 characters. Signatures built in a word processor or website builder often carry thousands of characters of hidden styling, which is the usual reason Gmail reports a signature as too long.

How to install signature HTML in your email client

The common mistake is pasting the raw code. Most signature editors are rich-text boxes, so the code shows up as text in every email. Install the rendered version instead.

  1. Save the code as a file ending in .html and open it in Chrome, Edge, Firefox or Safari.
  2. Select the whole signature with your mouse, or press Ctrl+A (Cmd+A on a Mac), and copy it.
  3. Paste into your client's signature settings and save.

Test the received email, not the editor

  1. Send a test to a Gmail address and an Outlook address, and open each on desktop and on a phone.
  2. Switch to dark mode and check the text and logo are still readable.
  3. Reply to the test and forward it, then check the signature in the reply.
  4. Open the test with images turned off and confirm your contact details still show.

Frequently asked questions

How do I write HTML code for an email signature?

Build the layout with a table, put every style inline on the element it affects, load images from public HTTPS URLs with width and height set, and keep the code to a few kilobytes. Open the finished file in a browser, copy the rendered signature, and paste it into your email client's signature settings.

Can I paste HTML code directly into Gmail's signature box?

No. Gmail's signature editor is a rich-text box, so pasted code appears as plain text. Open the HTML file in a browser, select the rendered signature, copy it, and paste that into Gmail instead.

Why use tables instead of divs in an email signature?

Classic Outlook for Windows renders email with Microsoft Word's engine, which ignores flexbox, grid, floats and most positioning. Tables are the one layout method that holds up in Outlook, Gmail, Apple Mail and mobile apps alike.

Should email signature CSS go in a style tag?

No. Signature editors and many email clients strip style blocks and class names when a signature is pasted or forwarded. Put each style in a style attribute on the element it applies to.

How long can email signature HTML be?

Gmail limits signatures to 10,000 characters, and that count includes the HTML. A typical table-based signature with hosted images is well under that. Embedded images and copied styling from word processors are what usually push a signature over.
