    View API quick start

    POST /api/v1/signatures/batch
    Headers: Authorization: Bearer YOUR_BULK_KEY and Content-Type: application/json.

    {
  "template": "classic",
  "defaults": { "company": "Acme Studio" },
  "style": { "primaryColor": "#0891b2" },
  "employees": [
    { "fullName": "Alex Morgan", "email": "alex@example.com" },
    { "fullName": "Sam Lee", "title": "Designer" }
  ]
}

    JSON responses contain total, valid, invalid and results. Each result has its employee row number, HTML, plain text and field errors. Add ?format=zip for a ZIP of valid rows, with a manifest and error report. Row numbers start at 1 in the employee list.

    GET /api/v1/templates lists template IDs, names and your batch limit using the same access key. Individual: up to 19 employees per batch. Team: up to 250. Requests allow 1 MB of JSON. Rate limit: 25 requests per minute per purchase, shared by API and MCP, including replacement keys.

    Supported employee fields: fullName (required), title, company, phone, email, website, photoUrl, logoUrl, linkedin, instagram, facebook, google, ctaText, ctaUrl, nameLinkUrl. Use text values and full HTTP(S) URLs. Defaults accept shared fields, excluding names, email addresses, photos and name links.

    Duplicate email addresses and invalid rows are reported, not overwritten. A ZIP with no valid rows returns 422. Invalid input returns 400, oversized requests 413, missing or invalid access 401, rate limits 429, and unavailable access configuration 503. Staff data is processed in memory and is not retained.
