How to add your signature to Gmail

  1. Click "Copy for Gmail" in the generator
  2. Open Gmail and click the gear icon (top right)
  3. Click "See all settings"
  4. Scroll to the "Signature" section
  5. Click "Create new" and give it a name
  6. Click inside the editor, press Ctrl+A then Ctrl+V
  7. Scroll down and click "Save Changes"

Gmail setup details that matter

Gmail's signature editor accepts pasted rich HTML, but it does not behave like a normal website editor. It keeps inline table layouts, links, images, colours, and basic typography, then strips anything it considers unsafe or unsupported. That is why the safest Gmail signature uses inline styles, hosted images, and simple table structure instead of external CSS.

After pasting, scroll below the editor and choose the signature as the default for new emails and replies. Many people save the signature but leave both default dropdowns set to "No signature", which makes it look like Gmail ignored the paste. Send one test email to yourself after saving, then check it in Gmail desktop and Gmail mobile before rolling it out.

  • Use the rich HTML copy button, not plain text, when pasting into Gmail.
  • Keep the signature under 10KB when possible so long email threads do not get clipped.
  • Use hosted HTTPS image URLs for profile photos and logos.
  • Use simple text links for email, phone, website, and calendar CTAs.

Images, logos, and profile photos in Gmail

Gmail can display images in a pasted signature, but the image source needs to be reachable by recipients. A local file path from your computer will not work after the email is sent. Upload your logo or headshot to a stable HTTPS URL, use reasonable dimensions, and add alt text so the signature still makes sense if a recipient blocks remote images.

For profile photos, square source images are the least fragile. The generator can preview circles and rounded corners, but some email clients simplify border radius handling. If your brand depends on an exact crop, test it in Gmail, Outlook, and Apple Mail before sending high-volume campaigns.

  • Avoid base64 image data because it increases message size quickly.
  • Use explicit width and height attributes on important images.
  • Keep logo files compressed and visually legible at small sizes.
  • Add descriptive alt text for photos, badges, and company logos.

Gmail mobile and dark-mode behavior

Gmail mobile does not always mirror the desktop default signature settings. If you use the Gmail app, open mobile settings and confirm the account does not have a separate mobile signature overriding the desktop version. If the mobile signature field is enabled with old text, Gmail can append that instead of the HTML signature you just created on desktop.

Dark mode is the other common failure point. Gmail may recolour pure black text, grey text, or transparent backgrounds in dark inboxes. Use strong contrast, avoid relying on transparent logo artwork, and test the finished HTML in the free health check before sending it to clients or customers.

  • Disable or update Gmail's separate mobile signature field.
  • Avoid pure black text on transparent backgrounds.
  • Use brand colours as accents, not as the only readable text colour.
  • Run the signature through the health check before rollout.

Gmail signature troubleshooting

Formatting disappears after paste

Copy the rich HTML version again, click inside Gmail's signature editor, and paste directly with Ctrl+V or Cmd+V. Do not paste through a plain-text intermediary such as a notes app.

The image looks broken

Check that the image URL starts with https:// and opens in a private browser window. If it only opens on your computer, recipients cannot load it.

The signature does not appear

Return to Gmail Settings and set the signature as the default for new emails and replies. Saving the signature alone does not always make it active.

The mobile app shows an old signature

Open Gmail mobile settings for the same account and update or disable the mobile signature override.

Gmail may recolour text and backgrounds so messages remain readable in dark inboxes. Signatures with transparent backgrounds, pure black text, and low-contrast greys are most likely to change. Use explicit background colours and run the finished HTML through the health check before publishing it.

Why is my Gmail signature image an attachment?

This usually happens when the signature uses a local image or pasted image blob instead of a hosted HTTPS image URL. Use a hosted image URL and paste the full HTML signature rather than dragging an image into the editor.
