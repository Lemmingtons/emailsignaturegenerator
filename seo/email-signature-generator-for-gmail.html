How to add your signature to Gmail

  1. Create and preview your signature in the email signature generator.
  2. Use Copy for Gmail to copy the rich HTML version.
  3. In Gmail on the web, select the gear icon, then See all settings.
  4. In the Signature section, create a signature or select the one you want to replace.
  5. Click in the editor and paste with Cmd+V or Ctrl+V.
  6. Choose that signature as the default for new emails and for replies or forwards, then select Save Changes.
  7. Send a test message and run the finished HTML through the signature health check.

Set Gmail defaults after you paste

Gmail's signature editor accepts pasted rich HTML, but it is not a web page editor. It keeps simple inline table layouts, links, images, colours, and basic typography, then removes markup it does not support. Use the generator's rich HTML copy rather than rebuilding the design in Gmail.

Creating a signature is not enough on its own. Set it as the default for both new messages and replies or forwards, then save the page. If either dropdown still says No signature, your new block can look as though it was never saved.

  • Paste directly into Gmail rather than through a plain-text notes app.
  • Use a short reply signature if long email threads are common.
  • Send a test email to a separate inbox after every material edit.
  • Keep contact links as normal text links so they remain useful when images are blocked.

Use reliable images and simple HTML

An image that lives only on your computer cannot load for recipients. Use a stable HTTPS image URL for a logo or photo, give important images explicit dimensions, and include meaningful alt text. The signature should still make sense when an inbox blocks remote images.

Gmail is most dependable with tables and inline styles. Avoid external CSS, base64 images, and decorative techniques that depend on browser layout behaviour. If the exact image crop matters to your brand, test the sent signature in more than one email client.

  • Use compressed logos and photos that stay legible at small sizes.
  • Avoid relying on transparent artwork as the only visible brand element.
  • Do not use a local file path as an image source.
  • Review the signature examples before simplifying an overloaded layout.

Check mobile and dark mode separately

The Gmail mobile app can use a separate mobile signature. If that field contains older text, Gmail may append it or show it instead of the HTML signature configured on desktop. Check the setting for the same account after you save the web version.

Gmail dark mode can recolour text or backgrounds. Strong contrast, visible links, and a signature that does not depend on transparent backgrounds make the result more resilient. The health check helps catch contrast and client-specific concerns before you send important mail.

  • Update or disable Gmail's separate mobile signature override.
  • Avoid low-contrast grey text as the only contact treatment.
  • Open the test message in Gmail on desktop and mobile.
  • Use the health check after changes to colours, logos, or trackers.

Gmail signature troubleshooting

Formatting disappears after paste

Copy the rich HTML version again, click directly inside Gmail's signature editor, and paste with Cmd+V or Ctrl+V. Do not paste through a plain-text editor.

The image looks broken

Confirm the image URL begins with https:// and opens in a private browser window. If it only opens on your computer or company network, recipients cannot load it.

The signature does not appear

Return to Gmail Settings and assign the signature as the default for new messages and replies or forwards before saving changes.

The mobile app shows an old signature

Open Gmail mobile settings for that account and update or disable the separate mobile signature.

Why does Gmail change my signature colours in dark mode?

Gmail may recolour text and backgrounds so messages remain readable in dark inboxes. Transparent backgrounds, pure black text, and low-contrast greys are more likely to change, so test the finished signature before publishing it.

The same signature can be used in Gmail for personal accounts and Google Workspace accounts. If an administrator manages signatures centrally, follow that policy before replacing the individual signature.
