How to add your signature to Outlook

  1. Click "Copy for Gmail" in the generator; it copies rich HTML that Outlook can paste
  2. Open Outlook → Settings → Compose and reply
  3. Under Email signature, click "+ New signature"
  4. Paste with Ctrl+V (Cmd+V)
  5. Click Save and set as default

Which Outlook signature settings to use

Outlook has several interfaces, and the signature settings move slightly between them. In Outlook on the web and new Outlook for Windows, look for Settings, Mail, then Compose and reply. In classic Outlook for Windows, use File, Options, Mail, then Signatures. Outlook for Mac keeps signatures under Outlook, Settings, Signatures.

After creating the signature, set it as the default for both new messages and replies or forwards. Outlook can store multiple signatures, so creating the HTML block is only half the job. The default dropdowns decide whether the signature appears automatically when you compose.

  • Use Outlook on the web for the cleanest paste experience if classic Outlook mangles spacing.
  • Set defaults for new messages and replies separately.
  • Keep one simple signature for replies if long email threads matter.
  • Send test emails to Gmail and Apple Mail as well as Outlook.

Outlook rendering rules

Classic Outlook on Windows uses Microsoft Word's rendering engine, which is stricter than browser-based email clients. It does not reliably support flexbox, grid, external stylesheets, advanced positioning, or modern responsive CSS. A signature that looks good in a browser can still break in Outlook if it depends on those patterns.

The safest Outlook signature is built with tables, inline styles, fixed image dimensions, and conservative spacing. That is the format the generator outputs. Keep decorative elements simple, avoid background images, and make sure the signature remains readable if a recipient's client blocks remote images.

  • Use table-based layout instead of flexbox or CSS grid.
  • Keep CSS inline rather than in a style block.
  • Avoid background images and absolute positioning.
  • Use standard fonts such as Arial, Georgia, Verdana, and Tahoma.

Microsoft 365, teams, and shared brands

For one person, pasting a generated signature into Outlook settings is enough. For a small team, create a single brand version first, test it across Outlook desktop and web, then duplicate it with each person's name, role, phone, and calendar link. This avoids every staff member improvising fonts, colours, or logo sizes.

If your Microsoft 365 admin manages signatures centrally, use the generated HTML as the approved source and hand it to the admin instead of asking each user to paste it. Centralized deployment is useful for disclaimers and brand control, but individual Outlook settings are still the fastest path for freelancers, founders, and small teams.

  • Create one approved brand signature before duplicating it for staff.
  • Keep legal disclaimers short so they do not dominate every reply.
  • Use hosted images so signatures work outside the company network.
  • Document the exact colour values and link targets used in the signature.

Outlook signature troubleshooting

Outlook changes spacing

Use the table-based HTML copy and avoid editing spacing inside Outlook after paste. Manual edits can introduce Word-specific markup that changes row heights.

Images show as blank boxes

Use publicly reachable HTTPS image URLs with explicit width and height. Ask recipients to download pictures only after confirming the image URL itself works.

The signature works on web but not desktop

Classic Outlook for Windows is stricter than Outlook web. Remove flexbox, grid, background images, and style blocks, or recreate the signature with the generator.

Replies become too long

Create a shorter reply signature with name, role, phone, and website only. Use the full signature for new conversations.
