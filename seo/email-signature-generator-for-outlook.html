How to add your signature to Outlook

  1. Create and preview the signature in the email signature generator.
  2. Copy the rich HTML version with Copy for Gmail; the same table-based HTML can be pasted into Outlook.
  3. In Outlook on the web or new Outlook for Windows, open Settings, then Mail and Compose and reply.
  4. In classic Outlook for Windows, use File, Options, Mail, then Signatures. In Outlook for Mac, use Outlook, Settings, then Signatures.
  5. Create or select a signature, paste into the editor, save it, and select defaults for new messages and replies or forwards.
  6. Send a test email to Gmail and Apple Mail, then use the signature health check to review the HTML.

Find the right Outlook signature settings

Outlook has several interfaces, so the setting location depends on which one you use. Outlook on the web and new Outlook for Windows place it in Settings, Mail, Compose and reply. Classic Outlook for Windows uses File, Options, Mail, Signatures, while Outlook for Mac has its own Signatures settings.

After creating the HTML block, choose it as the default for new messages and replies or forwards. Outlook can store several signatures, which means a valid signature can still fail to appear if the default dropdowns are left unset.

  • Use Outlook on the web for a clean paste if classic Outlook changes spacing.
  • Set new-message and reply defaults separately.
  • Keep a shorter reply signature for long conversations.
  • Send test messages to multiple clients before a team-wide rollout.

Design for classic Outlook on Windows

Classic Outlook for Windows uses Microsoft Word to render messages, so browser layout techniques can fail even if they look correct in a preview. Flexbox, grid, external style sheets, advanced positioning, and background images are particularly fragile.

A table-based layout with inline styles, fixed image dimensions, and simple spacing is more dependable. Keep the signature readable with images blocked, and use familiar fonts rather than depending on a font installed only on your own machine.

  • Use tables rather than flexbox or CSS grid.
  • Keep styling inline instead of in a style block.
  • Avoid background images and absolute positioning.
  • Use publicly reachable HTTPS images with explicit dimensions.

Prepare a signature for teams and Microsoft 365

For an individual, adding the generated HTML in Outlook settings is enough. For a small team, test one approved layout across the Outlook versions in use, then duplicate it with each person's contact details. This keeps logo sizes, colours, and links consistent without asking everyone to redesign the signature.

If a Microsoft 365 administrator manages signatures centrally, use the tested HTML as the approved layout and follow the administrator's distribution process. A centrally managed signature may replace individual settings, so confirm the chosen policy before staff make local changes.

  • Test the shared layout in Outlook desktop and web first.
  • Keep legal text short so it does not bury contact details in replies.
  • Use hosted images that work outside a company network.
  • Document the exact links and colour values used in the approved layout.

Outlook signature troubleshooting

Outlook changes spacing

Paste the table-based HTML and avoid rebuilding spacing inside Outlook. Manual edits can add Word-specific markup that changes row heights.

Images show as blank boxes

Use publicly reachable HTTPS image URLs with explicit width and height. Confirm the image itself loads outside your logged-in browser.

The signature works on web but not desktop

Classic Outlook for Windows is stricter than Outlook on the web. Remove browser-only layout techniques and recreate the signature with a simple table-based layout.

Replies become too long

Create a shorter reply signature with only the name, role, phone number, and website, while keeping the fuller version for new conversations.
