How to add your signature to Apple Mail

  1. Create and preview the signature in the email signature generator.
  2. Copy the rich HTML version with Copy for Gmail.
  3. Open Mail on your Mac, then choose Mail, Settings, and Signatures.
  4. Select the account, add or choose a signature, and turn off Always match my default message font before you paste.
  5. Click inside the editor and paste with Cmd+V, then choose the signature for new messages and replies if you use different defaults.
  6. Send a message to Gmail or Outlook, then use the signature health check to review the finished HTML.

Use the macOS signature editor without flattening the design

Apple Mail has a native signature editor for each account. Before pasting rich HTML, disable Always match my default message font; otherwise Mail can replace the intended font treatment with your compose font. Paste into the selected signature editor and set the relevant defaults after the content is in place.

Keep the design simple enough to survive forwarding and replies. Tables, inline styles, and a clear text-first contact block are safer than decorative layout tricks. If Mail changes the pasted content, copy the generated rich HTML again and avoid editing it through a plain-text app.

  • Select the correct sending account before creating the signature.
  • Disable the default-message-font option before pasting.
  • Use separate new-message and reply defaults when needed.
  • Send a test before deleting an older working signature.

Plan for iPhone and iPad separately

The Mail app on iPhone and iPad uses its own signature setting. A signature configured in Mail on a Mac does not automatically become the mobile signature for every account. Treat the mobile setting as a separate decision: use a compact text version, or leave it disabled if you do not want it appended to messages.

When a recipient opens your message on mobile, the important test is whether your name, role, contact details, and links remain easy to use. Avoid wide rows, tiny text, and information that only appears in an image.

  • Review Settings, Apps, Mail, Signature on iPhone or iPad for the sending account.
  • Keep the mobile version shorter than a desktop brand signature.
  • Make phone numbers and websites easy to tap.
  • Test a sent message in both portrait and dark mode.

Keep images and colours reliable in Apple Mail

Use hosted HTTPS URLs for photos and logos, rather than local file paths. Give important images sensible dimensions and alt text, and make sure the text contact block stands on its own when an inbox blocks remote images.

Apple Mail can display a broad range of formatting, but recipients may read the same message in Gmail or Outlook. Test with a dark background as well as a light background, keep contrast strong, and use the health check if you change colours or tracking links.

  • Use stable HTTPS image URLs and compressed assets.
  • Avoid transparent logos that disappear against a dark background.
  • Use normal text links for core contact actions.
  • Review the signature examples for layouts that stay compact on mobile.

Apple Mail signature troubleshooting

Apple Mail changes the font after paste

In Mail Settings, Signatures, turn off Always match my default message font before pasting the rich HTML version again.

The signature appears in one account but not another

Apple Mail stores signatures by sending account. Select the intended account in Mail Settings, Signatures, then set that signature as the default for the account.

My iPhone still adds old text

Update or disable the separate Mail signature in iPhone or iPad settings. The mobile signature is configured independently from the Mac version.

A logo disappears for recipients

Replace any local or private image source with a publicly reachable HTTPS URL, and confirm it loads outside your logged-in browser.
